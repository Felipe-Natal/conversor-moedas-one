# Conversor de Moedas

## Descrição
Este projeto é um **Conversor de Moedas em Java** que permite ao usuário converter valores entre diferentes moedas em tempo real, utilizando a **Exchange Rate API**. O usuário interage via console e escolhe entre 6 opções de conversão:

- Dólar → Real
- Real → Dólar
- Dólar → Euro
- Euro → Dólar
- Real → Euro
- Euro → Real

As taxas de câmbio são obtidas **dinamicamente** da API, garantindo valores atualizados.

## Tecnologias utilizadas
- Java 17 (ou superior)
- Gson (para desserialização do JSON)
- Exchange Rate API (gratuita)
- IntelliJ IDEA
